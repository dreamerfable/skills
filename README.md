# skills

个人编写的 AI Skills 集合，收录可公开分享、可复用的通用技能。

## 收录范围

- 只提交自己编写或有权公开分享的内容。
- 不包含内部接口、非公开业务规则、真实业务数据或个人敏感信息。
- 不包含密钥、令牌、账号凭据、本机绝对路径或本机专属配置。
- 需要凭据的脚本通过环境变量读取；配置示例仅使用占位符。

## 目录结构

```text
skills/
├── README.md
├── .gitignore
└── skills/
    └── <skill-name>/
        ├── SKILL.md
        ├── scripts/       # 可选：执行脚本
        ├── references/    # 可选：参考文档
        └── assets/        # 可选：模板等静态资源
```

每个 Skill 使用独立目录，目录名采用小写英文与连字符。仅创建实际需要的辅助目录。

## Skill 清单

暂未收录 Skill。添加第一个 Skill 时，在这里补充名称、用途和对应目录链接。

## 使用方式

1. 从清单中选择所需 Skill，先阅读其 `SKILL.md`。
2. 按所使用工具的 Skill 安装方式，安装对应目录。
3. 按该 Skill 的说明配置依赖和环境变量，并使用示例输入验证行为。

各工具的安装目录和支持能力可能不同，具体依赖与限制由各 Skill 单独说明。

## 新增与维护

1. 在 `skills/` 下创建独立目录，并添加 `SKILL.md`。
2. 明确用途、触发条件、输入、执行步骤、输出和失败处理方式。
3. 提供两三个典型示例，记录预期行为；有脚本时说明依赖与运行方法。
4. 检查正文、脚本、示例和附件，确认没有非公开信息或凭据。
5. 更新上方清单，检查 Git 差异后提交。

以本仓库作为源文件维护位置；修改后再同步到工具使用的安装目录。
